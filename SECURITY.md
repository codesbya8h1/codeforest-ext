# Security Policy

## Local analysis

CodeForest analyzes your workspace on-device. The Python backend binds to `127.0.0.1` and source code is not uploaded anywhere.

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Report them privately via [GitHub Security Advisories](https://github.com/codesbya8h1/codeforest-ext/security/advisories/new) on this repository.

Include:

- A description of the issue
- Steps to reproduce
- Affected version / commit if you know it

We will acknowledge the report and work on a fix before any public disclosure.
